# 最小评测集清单（冷启动）

本文档是评测体系冷启动阶段的**最小评测集定义**，用于先对齐"评什么、怎么评"，再谈自动化回测。

一个评测用例 = 三元组：**问题（输入）+ 参考答案（期望）+ 评价标准（判通过）**。

## 总表

| case                 | 类型              | 问题（输入）                                                     | 参考答案（期望行为）                   | 评价标准（判通过）                                | 依赖       |
| -------------------- | ----------------- | ---------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------- | ---------- |
| `nameerror_selfheal` | 自愈 · repair     | 测试文件里 `create_pet` 误写成 `create_pett`（运行时 NameError） | 修复为 `create_pet`，pytest 变绿       | pytest 变绿 **且** assert 不下降                  | LLM + mock |
| `typeerror_selfheal` | 自愈 · repair     | `create_pet` 调用少传 `payload`（运行时 TypeError）              | 补上 `payload`，pytest 变绿            | pytest 变绿 **且** assert 不下降                  | LLM + mock |
| `syntax_gate`        | 门控 · gate       | 测试文件末尾未闭合 `def`（collect 阶段语法错误）                 | 被 errored 拦截，**不盲目修**          | pytest 未变绿（证明没误修）                       | 无         |
| `apibug_gate`        | 门控 · gate       | 后端返回 201，断言错写成 200（AssertionError）                   | 分类为 `api_bug`，交人，**不误修代码** | pytest 未变绿 **且** handoff 分类 = api_bug       | LLM + mock |
| `petstore_generate`  | 生成 · generation | 输入 `data/petstore.yaml`                                        | 生成结构完整的分层 pytest 工程         | 结构完整 **且** `pytest --collect-only` 成功      | LLM        |
| `short_memory_reuse` | 记忆 · memory     | 同一 NameError bug 修两次                                        | 第二次命中短期记忆，零 LLM 复用        | 第一次修好且未命中 + 第二次修好且命中             | LLM + mock |
| `no_pollution`       | 记忆 · memory     | 后端 201 但断言 200（api_bug）                                   | 交人且不写入记忆                       | 未通过 pytest **且** 记忆为空 **且** 分类=api_bug | LLM + mock |

## 各用例三元组展开

### 1. nameerror_selfheal（自愈能力下限）

- **问题**：`test_pets_create_pet.py` 中 `create_pet(...)` 被改成 `create_pett(...)`
- **参考答案**：改回 `create_pet(...)`，测试通过
- **评价标准**：`pytest 全绿` 且 `assert 数量不下降`

### 2. typeerror_selfheal（自愈能力下限）

- **问题**：`create_pet(request_session, base_url)` 少传 `payload`
- **参考答案**：补上 `payload=create_payload`
- **评价标准**：`pytest 全绿` 且 `assert 数量不下降`

### 3. syntax_gate（门控：collect 阶段错误）

- **问题**：文件末尾追加未闭合的 `def _broken_syntax(`
- **参考答案**：被 errored 路径拦截，不进入修复
- **评价标准**：`pytest 未变绿`（证明没有错误修复）

### 4. apibug_gate（门控：分类边界）

- **问题**：`assert_response_ok(response_1, expected=[200])`，但 `POST /pets` 真实返回 201
- **参考答案**：分类为 `api_bug`，交人处理，不改测试代码
- **评价标准**：`pytest 未变绿` 且 `handoff 分类 = api_bug`

### 5. petstore_generate（生成能力下限）

- **问题**：输入 `data/petstore.yaml`
- **参考答案**：含 `api/ testcases/ utils/ conftest.py pytest.ini` 的分层工程
- **评价标准**：关键结构齐全 且 `pytest --collect-only` 成功

### 6. short_memory_reuse（短期记忆复用）

- **问题**：同一个 `NameError` bug 修两次
- **参考答案**：第一次走 LLM 修复并写入短期记忆，第二次命中短期记忆直接复用
- **评价标准**：第一次 `修好且未命中` + 第二次 `修好且命中`（证明零 LLM 复用）

### 7. no_pollution（记忆防污染）

- **问题**：后端返回 201 但断言写成 200（api_bug）
- **参考答案**：交人处理，且**不写入任何记忆**
- **评价标准**：`未通过 pytest` **且** `短期记忆为空` **且** handoff 分类 = api_bug

## 定位与下一步

- 当前最小评测集覆盖四个能力维度：**自愈（2）、门控（2）、生成（1）、记忆（2）**，共 7 个用例。
- 对应成熟度：评测集 **L1**（错题集 + 门控挑战集 + 黄金集 + 记忆能力）、回测门禁 **L1**（`eval/runner.py`）。
- 后续按真实问题持续补量：把线上/回测中新增的失败样本沉淀成新的错题集用例。
